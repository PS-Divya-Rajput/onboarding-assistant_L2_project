Prerequisites: Ensure you have Rust 1.84+ (stable toolchain) and Cargo installed via rustup.

Follow these four steps to fetch the repository and compile the main binary cleanly without incurring full-workspace build overhead:

1. Clone and enter repository bash
# Clone via HTTPS or SSH
git clone https://github.com/astral-sh/ruff.git
cd ruff
2. Build the primary Ruff binary cargo
# Fast build targeting only the CLI crate
cargo build --package ruff

Tip for new contributors: Ruff is structured as a large Cargo workspace with over 20 sub-crates. Specifying --package ruff avoids building benchmarks and internal documentation generators on your first cycle, saving approximately 40% compilation time.

3. Verify your build with linter unit tests cargo
cargo test --package ruff_linter
